# v0.2.0 Release Plan (temporary; delete after release)

**Status**: in progress · **Release**: v0.2.0

All commits stay **local only** until examples and docs are aligned; GitHub push
happens at the very end (no intermediate noise on the remote).

## Scope — four features, five phases

| Phase | Feature | Notes |
|-------|---------|-------|
| 1 | MCP SDK v2 migration | `mcp>=2.0`, `FastMCP` → `MCPServer`, in-memory `Client` tests |
| 2 | Rule IDs | `# rule: <id>` trailing comment, `rule_id` on proof tree (see `docs/PLANS/rule_ids.md`) |
| 3 | `explain` tool | deterministic server-side proof-tree → natural language |
| 4 | KB preload | `EUCLID_KB_PATH` env / `--kb-path` flag, optional `knowledge` params, autogen digest in instructions |
| 5 | Examples + docs + release | align examples/docs, CHANGELOG v0.2.0, version bump, push + tag |

## Order rationale

Dependency-driven + risk-first: SDK migration first (infrastructure, unblocks
in-memory testing used by later phases, riskiest change done while surface is
small), Rule IDs before explain (explain cites rule IDs), KB preload last
(independent, benefits from v0.2 testing infra).

## Phase 1 — MCP SDK v2

- `pyproject.toml`: `mcp>=1.27,<2` → `mcp>=2.0`; regenerate `uv.lock`
- `server.py`: `from mcp.server.mcpserver import MCPServer`;
  `MCPServer("Euclid-MCP", instructions=...)` (default name would be `mcp-server`)
- Decorators `@mcp.tool()` unchanged; verify no `ctx`/`get_context()` usage
- Add in-memory tests with `Client(mcp)` in `tests/test_tools.py`
- Gate: ruff, mypy, pytest+cov; A/B example output; local commit

## Phase 2 — Rule IDs

Per `docs/PLANS/rule_ids.md` (delete that file after implementation):
- `models.py`: `KB.rule_ids: dict[int, str]` (index-aligned with `rules`);
  `ProofNode.rule_id: Optional[str] = None`
- `language.py`: capture `# rule: <id>` from raw line (after `_extract_strings`,
  before lowercase); error if on fact/query; populate `KB.rule_ids`
- `translator.py`: `_translate_rule` prepends `euclid_rule_id('ID')` to body;
  meta-interpreter decomposes `(euclid_rule_id(Id), Rest)` → `rule(Goal, Rest,
  BodyProof, Id)`; `proof_to_json` emits `rule_id` only when `Id \= null`
- `sanitizer.py`: blocklist `euclid_rule_id`; ID re-emitted as escaped Prolog
  string
- `server.py`: `check_kb` warns on duplicate rule IDs
- `prolog_bridge.py`: `_parse_proof` propagates `rule_id`
- Tests per plan + end-to-end `reason()` proof carries `rule_id`
- Output byte-identical when no IDs present

## Phase 3 — explain (deterministic)

- New `euclid_mcp/explain.py`: walk `ProofNode` (fact/rule/and/neg/true) → list
  of natural-language steps; cite `rule_id` when present
- `models.py`: `ExplanationResult` (per-solution explanation + substitutions)
- `server.py`: new tool `explain(knowledge, query, max_solutions, max_depth)` —
  calls `reason()` internally, returns explanations
- Tests: single fact, multi-hop, negation, zero solutions, with/without rule_id

## Phase 4 — KB preload

- `server.py`: loader at startup from `EUCLID_KB_PATH` env and `--kb-path` flag;
  validate via `check_kb`; fail-fast with clear message
- Tools `reason`/`diagnose`/`what_if`/`check_kb`: `knowledge`/`base_knowledge`
  become optional → empty falls back to preloaded KB (backward compatible)
- New `euclid_mcp/kb_summary.py`: extract digest logic from
  `examples/10_llm_vs_euclid/generate_kb_markdown.py`; append digest to server
  `instructions` (agent sees preloaded KB without extra calls)
- `integrations/euclid_api.py`: `--kb-path` flag for parity
- Tests: preload from file, explicit knowledge overrides, missing file,
  digest in instructions, tool schema (optional knowledge)

## Phase 5 — Examples, docs, release

- Align examples (extend `12_kb_check` or a demo to use `explain`)
- Docs: README (explain, KB preload, `rule_id` example), `docs/EUCLID_IR.md`
  (`# rule:` syntax), `AGENTS.md`, `integrations/README.md`
- `.opencode.json`: reasoning-engine agent instructions mention `explain` +
  preloaded KB
- Delete `docs/PLANS/rule_ids.md` and this file
- CHANGELOG: v0.2.0 entry (consolidates current Unreleased; v0.1.6 tag skipped)
- Version bump 0.2.0 in `pyproject.toml` + `euclid_mcp/__init__.py`
- Final gate (ruff, mypy, pytest+cov, A/B) → push + tag v0.2.0
